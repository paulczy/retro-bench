A · Bench Console

Clean modern tool. Left rail, centre content, always-open right inspector. SVG DIP chip drawing with legend-as-filter and flip-to-underside. Command palette search. Light + dark.

B · Field Manual

Warm paper and ink, numbered sections, breadcrumb trail, right-hand section index. Pinout as two mirrored signal tables with filter chips; margin-note callout per pin. Full-page index-style search. "Dim lamp" dark mode.

Notes

D · Silkscreen

The circuit board is the interface. Solder-mask green or black, silkscreen white, copper for the live thing. Machines and chips as footprints with designators; a copper trace runs from the selected pin to its detail.

Notes

E · Service Manual

A 1983 factory service manual opened flat. Paper and ink, one orange-red spot colour, numbered sections and figures, callouts with leader lines. Memory map as a drawing, keys as keystroke boxes.

Notes

F · Instrument

A bench analyzer. Putty-grey panel, one phosphor display (amber or green), soft keys that change per screen, a rotary knob that selects the machine. Pin detail as a scope-style cursor readout.

Notes

C · Terminal

Dark bench mode, amber or green accent. Persistent command line with mini-syntax ("ted pin 10", "/ras"). Hybrid pinout: chip glyph synced with a dense table. Right drawer for details. Number and letter keys drive navigation.
