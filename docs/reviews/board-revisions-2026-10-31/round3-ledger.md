# Round 3 fact-check ledger — Skeptic

Review date: 2026-10-31. Review copy only; no `src/` edits.

Verdicts apply to the **current data**, not merely to whether the proposed edit happened. `verify: true` is not evidence. WRONG means a source directly contradicts the data; OVERSTATED means a supported statement has been extended beyond its source; UNPROVABLE means the supplied/accessible evidence does not establish the claim. A log row can inherit a failure from one of its constituent records.

Coverage: A01–A37 correspond, in order, to **all 37 body rows** in Review round 2. B rows individually check the changed power records, including all fields, board restrictions, nested scope notes and source references. C rows unpack grouped ancillary items. Cross-referenced rows overlap; totals are audit-row totals, not independent defect counts. Array indices below are zero-based; step numbers are the displayed numbers. `records.json` is an evaluated snapshot of the current JS, not a source of historical facts.

Source locators below are relative to `review-out/src/`. `#page=N` means physical PDF page; for a single image, HTML page, JSON metadata response or plain-text document, page 1 means the sole document. Plain-text line numbers further narrow the reading. Existing render filenames use physical PDF pages. Sources were read directly; scanned drawing details were inspected as images, with an additional high-resolution CN4 crop saved as `render/round3-cn4.png`. `sources-map.txt` maps cached URL hashes back to current source URLs; `round3-fetch-more.json` records the additional manual downloads. No Classic Repair Toolbox / Commodore Repair Toolbox source was found in the scoped records or used as evidence. Ray Carlsen's original notes are separately identified secondary sources, not that toolbox.
