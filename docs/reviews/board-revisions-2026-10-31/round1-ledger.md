Coverage: all 140 required records: 24 board definitions, 13 chipBoards maps, 25 locByBoard values and 78 tagged records. Board identities, names, absent years fields and each atomic note claim are separate rows. Tagged schematic year spans are assessed separately; a dated drawing is not a production history. Additional rows audit risky universal records and unavailable provenance.

Verdicts: OK = supported within the stated scope; WRONG = contradicted (source reading provided); OVERSTATED = documented variant represented as broader coverage; UNPROVABLE = available evidence insufficient. An OK tag does not certify every unrelated electrical, licensing or historical claim in the wider repair dataset. Record rows assess tag applicability and revision-related text; specific unsupported anecdotes and photo provenance are separate rows.

All cited in-scope landing pages/drawings were requested independently. sources.json records original URL, fetch URL, status, bytes and downloaded path. HTTP URLs were fetched using HTTPS. GitHub landing pages were opened before raw artifacts; Archive landing pages and metadata were opened before PDFs/ZIP. Scanned evidence was rendered and read visually; render/ includes original-resolution crops for decisive designators and part numbers. Text extraction served only navigation. Commons originals were inaccessible; local repository photos are explicitly identified as such.
