# batch-03 source fact-check ledger

227 items, indices 0-226, reviewed against downloaded cited sources. No application data edited.

Each row covers the pin number, label, direction and description, including any probe note. One decision per item: WRONG takes precedence over a supported remainder; UNVERIFIABLE means at least one material claim remains unsupported. Pin aliases D0-D7 for ROM O1-O8 preserve zero-based bus numbering. Host-machine tags and display categories are context; this ledger adjudicates the listed pin/replacement claims.

Principle mapping: all unsupported claims concern prove-it-works; contradictory data also concern fix-root-causes. serialize-shared-state-mutations: not applicable to this read-only document review.

## Source access and citation notes

- Zimmers downloads all returned HTTP 200. ZIP scans were extracted and actual pin diagrams/signal descriptions read as PNGs; PDFs were processed with pdftotext -layout and relevant pages rendered using pdftoppm -f N -l N -r 110 -png.
- HTTPS initially failed in local curl with Schannel SEC_E_NO_CREDENTIALS. Python urllib retrieved FPGASID and WDC successfully; these are not dead links.
- FPGASID home: http://www.fpgasid.de/ redirects to https://www.fpgasid.de/. Home and linked Specifications support FPGA replacement and dual-SID stereo; comparative clone pricing is absent.
- Both cited Wayback URLs were inaccessible in urllib (connection refused) and web open. Search was attempted; the original portcommodore HTTP URLs both returned 406 Mod_Security. Treat as blocked, not proven dead. Secondary mirrors were not used as proof.
- VIC-20 PRG cited p.212 / #page=228 is wrong for the pin configuration: actual diagram p.213 / PDF229. P.212 is features. All 33 VIC records carry this citation-location issue; alternate MOS diagram remains usable.
- C64 PRG p.403 / PDF422 prints PHI2 IN at CPU pin39. CSG 6510 p.1 and service circuit show PHI2 OUT. Source erratum; item71 is correct.
