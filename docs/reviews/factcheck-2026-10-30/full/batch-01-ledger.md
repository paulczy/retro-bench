## Source access and locator audit

Every distinct cited URL was requested using curl -L -A Mozilla/5.0 into the batch folder. HTTPS curl failed locally with Schannel SEC_E_NO_CREDENTIALS; urllib retrieved the same documents. This local TLS-client issue does not prove a dead source. PDFs were extracted using pdftotext -layout. Scanned pinouts, POKEY pages, and Disk II diagrams were rendered using pdftoppm -f N -l N -r 110 -png and read visually; additional zooms/crops aided label reading. Saved source files are indexed below.

Blocked source: BBC Wayback schematic returned HTTP 429 through both HTTP and HTTPS; origin regregex returned HTTP 401. Web search recovered the primary Acorn 103,000/C drawing, labeled 4816A-3 at IC53-IC68, at 4corn. Original-source URL is not proven dead. Mirror read directly in 14-mirror.jpg and 14-dram.png: https://www.4corn.co.uk/archive/diagrams/103%2C000-C%20Circuit%20Diagram%20for%20BBC%20Microcomputer.jpg

Locator correction: MC6801RM PDF p.46 is printed p.3-1, not p.3-2 as citation says. Archive.org n220/n240/n242 are zero-based locators; printed pages 187/9-11/9-13 are correct. MOS redirects successfully to https://6502.org/documents/datasheets/mos/mos_6500_mpu_nov_1985.pdf .
