Verdicts concern the scoped new hardware value, not whether a verify flag is syntactically present. UNPROVEN is not a finding that the old value was false. Where the fix narrows an unsupported range to a documented nominal value, the new result can be CORRECT while the old result is UNPROVEN. Attributed community-source statements are identified as such and are not manufacturer electrical certification.

Method: read HEAD data with git show, current data with the data registration code, and actual git diff. Source manifest contains URLs, download status and TLS errors. curl -L -A Mozilla/5.0 was attempted for every original source; this environment curl fails with schannel SEC_E_NO_CREDENTIALS. Downloaded the same URLs with Python urllib and the same User-Agent, retaining source bytes here. Used pdftotext -layout; scanned cited pages were rendered with pdftoppm -f N -l N -r 110 -png and viewed. Protected book download returned401. Recovered dead CPCWiki articles through oldwiki; downloaded actual Internet Archive PDFs using metadata rather than treating reader HTML as evidence. Source artifacts are isolated in skeptic-b/ because other reviews also write this shared temporary directory.

Principles: prove-it-works governs every hardware verdict. fix-root-causes applies to generic/shared-chip leakage and the state-dependent charger corrections. serialize-shared-state-mutations: this review performs no shared data mutations and isolates its artifacts.
