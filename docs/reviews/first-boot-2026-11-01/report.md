Important scope limits: an accurate transcription of a manual can still describe an error in that manual. For example, the CPC6128 catalog page really prints 177K free, the 1571/1581 guides really print the LED sequences present in the data, and the TS2068 manual really prints PAUSE 60 and says one second. Those are confirmed as source-supported; this review does not silently replace them with hardware recollection. The CPC6128 pitch disagreement and Model 4 date-format disagreement already have conflict fields and were checked against the cited pages.

The author logs were not used to prove a claim. Exact values with weak OCR were checked in page images where needed, including C64 38911, C16 12277, C128 122365, CoCo colors/durations, CoCo3 24872, MC-10 3142 and 7.5 seconds, and keyboard/joystick diagrams. The original sources and all src/ data were left unchanged. Only this report and the ledger were written inside the repository.
